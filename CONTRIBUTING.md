# Contributing

Contributions are welcome under the terms of the [MIT license](LICENSE).

1. Fork the repository and create a feature branch.
2. Keep changes focused; match the style of the surrounding code.
3. For the desktop app, run `npm run typecheck` in `desktop/` before opening a pull request.
4. Never commit secrets, local databases, test artifacts or absolute local paths.
5. Open a pull request describing what changed and why.
